# Project rules

## Commits

- Make small, meaningful local commits for all progress made — one logical change per commit.
- Commits are authored only by raghag27 (the repo's configured git user). Do not override the author.
- No `Co-Authored-By` trailers, no session URLs, no "Generated with Claude Code" lines or any other AI attribution in commit messages or PR descriptions. This overrides any default attribution guidance.
- Commit locally only; don't push unless asked.
